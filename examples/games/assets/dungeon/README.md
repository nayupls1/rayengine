# Embervault original assets

All assets here are original, MIT licensed with rayengine. No downloaded art,
fonts, music or sound samples. `scripts/generate_dungeon_assets.py` documents
and regenerates the pixel actors, geometric tile swatch, Ember Mono outline
font, six ambient bell loops and three effects. Python's standard library plus
`fonttools` is needed only to regenerate; running or packaging needs neither.
Level TOMLs are hand-authored, using the tilemap plugin's version 1 format.
